# Contributing to neuroplast

Issue reports and pull requests are welcome. Contributions are accepted under
the repository's AGPL-3.0-only license; see [LICENSE](LICENSE). You retain
copyright in your original contributions.

Only submit work you have authority to license. Identify any third-party
materials and preserve their required notices.

Explain the problem, the resulting behavior, and how you verified the change
in each pull request. Run the typecheck, lint, and production build before submitting.
